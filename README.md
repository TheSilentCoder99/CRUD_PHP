# Catálogo de Productos - Aplicación Web PHP

## Descripción

Este proyecto ha sido desarrollado con fines educativos y de aprendizaje, con el objetivo de practicar el desarrollo web dinámico utilizando PHP y bases de datos relacionales.

La aplicación consiste en un sistema de gestión de catálogo de productos y fabricantes que implementa autenticación, control de acceso, operaciones CRUD y gestión de datos almacenados en MySQL.

Más allá de la funcionalidad final, el propósito principal del proyecto es adquirir experiencia práctica en conceptos fundamentales del desarrollo backend y la interacción entre frontend, servidor y base de datos.

---

## Objetivos de aprendizaje

Durante el desarrollo de este proyecto se han trabajado conceptos como:

* Desarrollo web dinámico con PHP
* Diseño y gestión de bases de datos relacionales
* Operaciones CRUD (Create, Read, Update, Delete)
* Gestión de sesiones y autenticación
* Control de acceso basado en usuarios
* Subida y gestión de archivos (imágenes)
* Paginación y filtrado de resultados
* Consultas SQL y relaciones entre tablas
* Organización y estructuración de proyectos web

---

## Contexto del proyecto

Este proyecto forma parte de un proceso de aprendizaje orientado a mejorar habilidades de desarrollo backend y bases de datos, priorizando la comprensión práctica de los conceptos sobre la complejidad técnica o la escalabilidad del sistema.
